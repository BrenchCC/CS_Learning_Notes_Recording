# 6.4 抛硬币问题
在本题中，我们将研究传统概率场景下的抛硬币问题，但会考虑两种变化情况。

第一种情况：硬币是非均匀的。用\(s\)表示抛硬币的结果（取值为正面\(H\)或反面\(T\)），则有：
\[p(s=H)=\alpha, \alpha \in[0,1] \tag{6.5}\]

第二种情况：你无法直接观察到硬币的结果，只能依靠一位朋友来告知抛硬币的结果。遗憾的是，你的朋友并不可靠——当实际结果为反面时，他有时会报告为正面，反之亦然。用\(r\)表示朋友的报告结果，则有：
\[p(r=T | s=H)=\theta_{1} \tag{6.6}\]
\[p(r=H | s=T)=\theta_{2} \tag{6.7}\]
其中\(\theta_{1}, \theta_{2} \in[0,1]\)。你的任务是：给定朋友的报告结果，推测出抛硬币的真实结果。


### (a)
若朋友报告结果为正面（\(r=H\)），在最小错误概率意义下，最优决策函数是什么？也就是说，何时应推测真实结果为正面，何时应推测为反面？


### (b)
考虑\(\theta_{1}=\theta_{2}\)的情况。你能否对(a)中推导得到的决策规则给出直观解释？


### (c)
你发现：若让朋友多次报告抛硬币的结果，他给出的多次报告在统计上是独立的。因此你决定让他报告\(n\)次，希望通过这种方式降低不确定性（注意：仍只进行一次抛硬币，但该结果会被报告\(n\)次）。此时，新的最小错误概率决策规则是什么？


### (d)
考虑\(\theta_{1}=\theta_{2}\)的情况，且假设朋友的\(n\)次报告结果全为正面（即报告序列为“全正面”）。你能否对(c)中推导得到的决策规则给出直观解释？
