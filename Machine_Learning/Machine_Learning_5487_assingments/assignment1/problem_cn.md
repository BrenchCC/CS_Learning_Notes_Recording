**问题 2.1 泊松分布与飞弹**

在第二次世界大战期间，德国向伦敦发射了V-1和V-2飞弹（远程导弹）。有些地区遭受了多次击中，英国军方想知道这些多次击中是由于德军针对特定区域，还是纯粹出于偶然。

为了分析这个问题，英国统计学家 R.D. Clarke 将伦敦一个144平方公里的区域划分成一个规则网格，形成了576个单元。在飞弹随机落下的假设下，击中任何单元的概率在所有单元中都是恒定的。因此，各单元的击中次数是来自一个共同随机变量 x 的独立同分布样本。

对一个固定时间段内发生事件（炸弹击中）次数进行建模的一个自然分布是泊松分布，其形式如下：

$$p(x=k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

其中 $k\in\{0,1,2,3,\cdots\}$ 是一个计数数字。参数 $\lambda$ 是事件的平均次数，其均值和方差相同：$E[x]=\operatorname{var}(x)=\lambda$。

(a) 给定一组独立同分布样本 $\left\{k_{1},\cdots, k_{N}\right\}$，推导 $\lambda$ 的最大似然估计。
(b) 证明该 ML 估计量是无偏的，并且估计量的方差是 $\frac{\lambda}{N}$。

下表列出了观测到有 k 次击中的单元数量（这是 Clarke 的实际数据！）。

| k (击中次数) | 观测到有 k 次击中的单元数量 |
| :---------- | :--------------------------- |
| 0           | 229                          |
| 1           | 211                          |
| 2           | 93                           |
| 3           | 35                           |
| 4           | 7                            |
| 5+          | 1                            |

(c) 使用上述数据，计算泊松分布的 ML 估计值 $\hat{\lambda}$。
(d) 使用估计值 $\hat{\lambda}$ 预测有 k 次击中的单元的期望数量，其中 $k\in\{0,1,2,3,4,5+\}$。将期望计数与观测数据进行比较。你可以得出什么结论？
